# 排班小助手 - AI智能排班系统

粉色主题的智能排班桌面/PWA应用，支持月/周视图、工资计算、AI助手、统计分析，数据按账号隔离保护隐私。

## 功能

### 核心功能
- **月度排班** - 日历视图，点击日期快速添加班次
- **周排班** - 七日列式视图，班次复制到次日
- **工资计算** - 自动计算工时和工资，品牌汇总
- **班次模板** - 保存常用班次配置，一键填充
- **语音输入** - 中文语音识别添加班次
- **CSV导出** - 按月/周导出排班数据

### AI功能
- **AI排班助手** - 浮动面板，自然语言对话
- **智能解析** - "5号早班欧莱雅9点到6点时薪30"自动识别
- **工资分析** - AI分析本月工资情况
- **优化建议** - 排班优化建议
- **冲突检测** - 自动检测时间冲突

### 统计分析
- 总工时、总工资、总班次、平均时薪
- 近6个月工时/工资趋势图
- 品牌分布、班次类型分布
- 详细排班记录表

### 其他
- **账号密码登录** - 数据按账号隔离，互不可见
- **深色模式** - 一键切换
- **数据导入导出** - JSON格式备份
- **PWA离线** - Service Worker缓存

## 使用

### 在线使用
直接打开 `index.html`，输入账号密码登录。

### 桌面应用
基于 Tauri，可打包为 Windows/macOS/Linux 原生应用。
